Psychology Analytics Workflow

Complete start-to-end flow: how psychology data is logged, stored, calculated, and shown in analytics.

1. Purpose

The psychology system turns each trade into more than entry, exit, and P&L. It records the trader's mental state, confidence, emotional triggers, and review judgment. Analytics then compares those states against actual performance.

2. Data Captured Per Trade

Entry Basis

Stored as entryBasis.

  • Plan - trade followed a planned setup.
  • Emotion - trade came from emotion.
  • Impulsive - trade was rushed or unplanned.
  • Custom - user writes a custom reason.

Mood

Stored as mood, a number from 1 to 5.

  • 1 = Stressed
  • 2 = Anxious
  • 3 = Neutral
  • 4 = Good / Focused
  • 5 = Peak

Confidence

Stored as confidence.

  • Low
  • Medium
  • High
  • Overconfident

Emotional Tags and Retake

Stored as emotionalTags and wouldRetake.

  • Tags: FOMO, Revenge, Fear, Greed, Calm, Focused, etc.
  • Would Retake: Yes or No.

5. Save Payload

When a trade is saved, the frontend sends a trade payload similar to:

{
  entryBasis: "Plan",
  mood: 3,
  confidence: "Low",
  emotionalTags: ["Calm", "Focused"],
  wouldRetake: "Yes"
}

The backend saves these values in the same Indian trade document as symbol, entry, exit, quantity, and P&L.

7. Backend Calculations

Mood vs Performance

Trades are grouped by mood level. For each mood bucket, backend calculates:

  • trade count
  • wins
  • losses
  • win rate
  • average P&L
  • total P&L

Confidence Calibration

Trades are grouped by Low, Medium, High, and Overconfident.

This shows whether the user's confidence is aligned with actual trade results.

Emotional Tag Impact

Trades are grouped by each emotional tag. This reveals which emotional states are profitable or harmful.

Would Retake Analysis

Trades are split into two review buckets:

  • wouldRetake === "Yes"
  • wouldRetake === "No"

Each bucket gets trade count, win rate, average P&L, and total P&L.

8. Psychology Score Formula

Final score is 0 to 100.

psychologyScore =
  planAdherencePct * 0.30
+ calmTradingPct  * 0.25
+ noRevengePct    * 0.20
+ goodMoodPct     * 0.15
+ wouldRetakePct  * 0.10
  • Plan adherence: how many trades followed the plan.
  • Calm trading: how many trades were tagged Calm or Focused.
  • No revenge: avoids larger-risk trades after a same-day loss.
  • Good mood: mood 3 or above.
  • Would retake: trades the user believes were worth repeating.

10. Psychology Insights

The frontend function generatePsychInsights() converts analytics numbers into practical coaching text. Examples:

  • Trade best when Neutral: generated from the best mood bucket.
  • Low confidence trades are profitable: generated if low-confidence trades have positive average P&L.
  • Calm state is your edge: generated if Calm/Focused tags perform strongly.
  • Greed trades cost you money: generated if a risk tag has negative average P&L.
